# الدفتر — تمرين وتغذية

تطبيق ويب عربي (PWA) بيجمع التمرين والتغذية في مكان واحد. البيانات ومفتاح الـ AI بيتحفظوا على جهازك بس.

## النشر على GitHub Pages
1. ارفع محتويات مجلد `dist/` (أو ملف `aldaftar-site.zip` بعد فكّه) في جذر الريبو.
2. Settings → Pages → Deploy from branch → `main` / root.
3. افتح اللينك من الموبايل → مشاركة → «إضافة إلى الشاشة الرئيسية».

## التطوير
```
npm install
npm run dev     # تشغيل محلي
npm test        # الاختبارات
npm run build   # يطلّع dist/
```

## الخصوصية
- مفتاح Anthropic بيتكتب من الملف ← «مفتاح Anthropic» وبيتحفظ على الجهاز بس، ومش بيدخل في الباك أب.
- متحطش أي ملف باك أب `.json` في الريبو.
